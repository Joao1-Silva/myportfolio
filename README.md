# Jonathan Silva — Portfolio

Portfolio bilingüe y estudio personal de software de Jonathan Silva. Presenta servicios, productos base y casos de estudio de desarrollo frontend, backend y experiencias interactivas.

## Contenido

- Presentación y propuesta de valor en español e inglés.
- Servicios y paquetes adaptables para landing pages, dashboards y MVPs.
- Casos de estudio reales: Mathgame 3D, vdolarjs y API Fluxcy.
- Formulario de brief que prepara un correo sin almacenar datos del visitante.
- Navegación responsive, animaciones con mejora progresiva y soporte para movimiento reducido.
- Opening cinematográfico con monograma 3D y tarjetas con profundidad interactiva en dispositivos compatibles.
- Escenas 3D contextuales activadas por scroll para servicios, productos, proyectos, capacidades y contacto.
- Metadatos Open Graph, Twitter Cards y datos estructurados de Schema.org.

## Tecnologías

HTML5, CSS3 y JavaScript sin framework. El sitio no requiere proceso de compilación.

## Desarrollo local

Instala las dependencias de validación:

```bash
npm install
```

Abre `index.html` directamente o sirve la carpeta con el servidor estático que prefieras.

## Validación

```bash
npm run validate
```

Este comando valida la estructura HTML y comprueba la sintaxis de JavaScript.
